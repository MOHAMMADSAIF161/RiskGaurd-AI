Operating Rule

Flag top orders by expected return loss

RiskGuard ranks orders by their expected financial exposure from a potential return and concentrates merchant review capacity on the highest-value risk.

How RiskGuard Calculates Expected Return Loss

The economic ranking logic behind order prioritization
Return Probability Predicted probability that the order is returned
×
Loss If Returned max(Profit Margin, 0) + Shipping Cost
=
Expected Return Loss Financial exposure used for ranking
Core formula: Expected Return Loss = Return Probability × Loss If Returned. The loss-if-returned definition is max(profit margin, 0) + shipping cost.

Why the Lift Matters

Business interpretation

At roughly a 10% review workload, the ranking strategy captures 42.48% of the realized loss proxy. That is 4.24 times the loss captured by randomly selecting 10% of orders.

Important: The dataset is synthetic and the loss measure is a transparent dataset-derived proxy. These results demonstrate ranking value, not money actually saved.
